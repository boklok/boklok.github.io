## 왜 만들었냐면

원래는 로컬 AI 모델(내 컴퓨터 안에서 돌아가는 AI, 인터넷 없이도 동작해요) 실습용으로 맥북을 쓰고 있었어요. 근데 맥북 에어 M5, 통합 메모리 16GB짜리라 실제로 여유 있게 쓸 수 있는 메모리가 9~10GB 정도밖에 안 돼요. 그러다 보니 "로컬 모델로 뭘 하겠다"보다는, 오히려 **Claude Code한테 자잘한 자동화를 시켜서 텔레그램으로 부려먹는 게** 훨씬 실용적이겠다 싶었어요. 그래서 방향을 틀어서, 폰에서 텔레그램으로 말 걸면 대신 조사하고, 매일 아침 브리핑해주고, 가격 떨어지면 알려주는 개인 비서 봇을 만들었습니다.

## 뼈대: 텔레그램 봇 + Claude Code CLI

봇 자체는 거창하지 않아요. 텔레그램에서 메시지가 오면:

- **URL을 보내면** → 가격 감시 목록에 자동 등록 (나중에 가격 떨어지면 알림)
- **"워치리스트"라고 보내면** → 지금 감시 중인 상품 목록
- **"최저가 알려줘" 같은 걸 보내면** → 다나와 + 에누리를 동시에 뒤져서 낮은 가격순으로 정리
- **위치를 공유하면** → 그 지역을 아침 브리핑 날씨 기준으로 저장
- **그 외 아무거나 물어보면** → `claude -p` 명령으로 Claude Code CLI를 호출해서 웹검색으로 답변

핵심은 이미 구독 중인 Claude Code Pro 사용량을 그대로 쓰는 거라, 별도 API 요금이 안 나간다는 점이에요. `subprocess.run(["claude", "-p", 프롬프트, ...])` 한 줄이면 웹검색까지 되는 답변을 텍스트로 받아올 수 있어요.

*(스크린샷 자리: 텔레그램에서 URL 보내고 "가격 감시 등록 완료" 답장 받는 화면)*

## 안전장치: "할 수 있는 일" 자체를 좁혀놓기

봇이 웹페이지를 열어서 가격을 확인하거나 검색해야 해서 Playwright(브라우저를 코드로 조종하는 도구)를 붙였는데, 여기서 신경 쓴 게 하나 있어요. AI가 실수로라도 장바구니에 담거나 로그인하거나 결제하는 일이 없도록, **애초에 그런 함수 자체를 코드에 만들지 않았어요.** "하지 마"라고 지시하는 게 아니라, 물리적으로 그런 동작을 할 수 있는 코드가 없는 거예요. `search`, `open_url`, `click_link`(보이는 링크 텍스트로만 클릭 가능) 이렇게 읽기 전용 동작만 존재합니다. AI에게 뭔가를 "하지 말라"고 프롬프트로 막는 것보다, 애초에 할 수 없게 만드는 게 훨씬 마음이 편하더라고요.

## 매일 아침 5시, 브리핑 하나로 하루 시작

`launchd`(맥에서 정해진 시간에 프로그램을 자동 실행해주는 기능)로 매일 오전 5시에 브리핑을 보내게 해뒀어요. 내용은:

- 한국 관련 뉴스 3개 + 해외 주요 뉴스 2개 (각각 근거 기사 링크 포함)
- 오늘 날씨
- 오늘의 운세 2줄 (그냥 재미로)
- 오늘 캘린더 일정
- 가격 감시 중인 상품 현황

전부 `claude -p`에 "이런 걸 웹검색해서 텔레그램용으로 짧게 정리해줘"라고 프롬프트 하나 던지면 끝이에요.

*(스크린샷 자리: 아침에 온 브리핑 메시지 전체 캡처)*

## 가격이 떨어지면 알려주는 워치리스트

다나와 같은 쇼핑몰 페이지를 열어서 본문 텍스트에서 "OO,OOO원" 형태 숫자를 정규식으로 긁어와 가장 큰 값을 "현재가"로 추정하는 방식이에요. 100% 정확하진 않지만(배송비·쿠폰가보다 상품가가 보통 더 크다는 가정), 등록할 때 한 번 확인하면 충분히 쓸만해요. 4시간마다 다시 확인해서 가격이 떨어졌거나 목표가에 도달하면 브리핑을 기다리지 않고 바로 알림을 보냅니다.

## 일정 30분 전 리마인더, 그리고 예상 못 한 삽질

캘린더 일정을 30분 전에 알려주는 기능을 추가하다가 재밌는 걸 발견했어요. macOS 캘린더 정보를 텍스트로 뽑아주는 `icalBuddy`라는 도구를 썼는데, 분명히 "URL 필드는 빼줘"라고 옵션을 줬는데도 일정에 걸린 링크가 계속 같이 딸려 나오는 거예요. 한참 파보니, 그 URL이 별도 필드가 아니라 **일정 제목(title) 자체에 줄바꿈으로 이미 섞여 들어가 있는** 경우였어요. 캘린더 앱이 동기화하면서 그렇게 만든 거죠. 결국 "제목의 첫 줄만 진짜 제목으로 취급하고 나머지는 무시한다"는 식으로 파싱을 다시 짰어요. 딱 봐서는 안 보이는, 진짜 데이터를 까봐야 알 수 있는 종류의 버그였어요.

## 알구몬 딜을 브라우저 없이 긁어온 이야기

핫딜 사이트인 알구몬 랭킹 페이지를 감시하는 기능을 만들면서는 반대로 운이 좋았어요. 이 사이트는 화면에 보이는 내용을 자바스크립트가 나중에 그려주는 방식(SPA)인데, 페이지 소스를 열어보니 **서버가 미리 만들어둔 딜 데이터(제목·가격·판매처)가 통째로 HTML 안에 박혀 있더라고요.** 덕분에 무거운 브라우저를 안 띄우고 `requests`로 페이지만 받아서 정규식으로 딜 정보를 뽑아낼 수 있었어요. 대신 그 과정에서 한글이 다 깨지는 인코딩 버그를 한 번 만났는데(`resp.encoding = "utf-8"`을 안 정해줘서 요청 라이브러리가 인코딩을 잘못 추측한 거였어요), 한 줄 고치니 바로 해결됐어요.

이렇게 가져온 새 딜 중에서 "30대가 관심 가질만한 것"을 고르는 건 규칙으로 딱 자르기 어려워서, 여기서도 `claude -p`한테 목록만 던지고 골라달라고 시켰어요. 실제로 돌려보니 생필품·가전·건강식품 같은 걸 잘 골라내고, 유아용품이나 특정 게임 굿즈 같은 건 알아서 걸러주더라고요.

## 커뮤니티 전체를 훑어서 "화제성" 판단하기

알구몬 하나만 보면 놓치는 게 있을 것 같아서, 뽐뿌·클리앙 같은 커뮤니티 전반을 `claude -p` + 웹검색으로 훑어서 "지금 반응이 뜨거운 특가"를 찾아주는 기능도 추가했어요. 근데 처음엔 30분마다 자꾸 "찾은 거 없음"으로 나오길래 이상해서 원인을 파봤더니, 여러 사이트를 검색하다 보니 원래 걸어둔 타임아웃(180초)을 자주 넘겨서 그냥 조용히 실패하고 있던 거였어요. 타임아웃을 넉넉하게 늘리고 나니 제대로 동작했어요. "AI가 이상하게 군다" 싶을 때 알고 보면 이런 단순한 설정값 문제인 경우가 은근 많더라고요.

*(스크린샷 자리: 텔레그램으로 온 특가 알림 메시지)*

## 주간 요약도 하나

매일 브리핑 내용을 파일에 조금씩 쌓아뒀다가, 일요일 저녁 8시에 지난 일주일치를 모아서 "이번 주 뉴스 흐름 + 가격 변동"을 한 번 더 요약해서 보내줘요. 매일 받은 걸 다시 훑어볼 필요 없이, 한 주를 정리하는 느낌으로 받아볼 수 있어서 나름 만족스러워요.

## 마무리하며

정리하고 보니 지금 이 맥북에서 상시로 돌아가는 자동화가 6개예요 — 브리핑, 가격 감시, 일정 리마인더, 알구몬 감시, 화제 특가 감시, 그리고 상시 대기 중인 봇 자체. 하나하나는 다 짧은 파이썬 스크립트에 `launchd` 스케줄 하나씩 붙인 정도라 거창하지 않은데, 모아놓고 보니 진짜 비서 하나 부리는 느낌이 나요.

느낀 점은, 이런 개인 자동화는 "완벽한 정확도"보다 "적당히 쓸만한 휴리스틱 + 문제 생기면 바로 고칠 수 있는 가벼움"이 더 중요하다는 거였어요. 가격 추출도, 일정 파싱도, 딜 필터링도 다 100% 정확하진 않지만, 어차피 내가 매일 보면서 감으로 걸러 쓰는 도구라 그 정도면 충분하더라고요.
